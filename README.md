# JARVIS Terminal (public dashboard)

Read-only snapshot of the JARVIS memecoin night desk so it can be opened and installed on a phone.

- Live site: https://ekpalmer6-lang.github.io/jarvis-dash/
- This repository holds **display data only**: balances, scans, trades, alerts, and pins.
- It does **not** contain wallet keys, cookies, account emails, or session information.
- Snapshots refresh about every 60 seconds when the publisher on Jarvis's computer is running.
- Pins are read-only here; ask Jarvis in chat to pin a coin.
- Research tool, not financial advice.
